# WagnerChess chess tools – source code

This repository contains the source code of the chess tools of wagnerchess.com (Analysis Room, library and related code), published under the GNU General Public License v3.0 (see LICENSE).

- The tools build on open-source projects, among them Stockfish (GPL-3.0), chessground and chess.js. See NOTICE.md and https://wagnerchess.com/tools/licenses
- The rest of the website (texts, layout, accounts, shop, videos) is NOT part of this repository.
- Some files of the tools import other small files of the website; these are included so the tool code is complete. Private data, keys and admin-only content are not included.
